Cómo traer noticias nuevas

El botón Refresh del dashboard solo vuelve a pedir el archivo noticias.json que ya está publicado. Para recopilar noticias nuevas se ejecuta el workflow desde GitHub:

  1. Abre tu repositorio en GitHub y entra a la pestaña Actions.
  2. Elige el workflow Actualizar noticias y publicar dashboard.
  3. Pulsa Run workflow y confirma con el botón verde Run workflow.
  4. Cuando el workflow termine y la página se publique, vuelve aquí y pulsa Refresh.
